# Институт гидроизоляции — сайт

## Структура
```
index.html
css/
  main.css      — токены (цвета, шрифты, отступы), reset, общие компоненты (.btn, .section-title, .section-lead, .show-more)
  header.css    — шапка
  hero.css      — первая секция
  projects.css  — произведённые работы (фото + город)
  docs.css      — документация
  about.css     — о компании
  support.css   — поддержка специалистов по всей России (карта)
  footer.css    — подвал
js/
  header.js     — бургер-меню
  show-more.js  — универсальная кнопка «Показать больше» (проекты, документы и любые другие секции)
docs/           — документы для скачивания (PDF, JPG)
img/            — изображения (фон hero, логотип и т.д.)
  works/        — фото произведённых работ (work-1…9.webp, placeholder.svg — заглушка)
```

## Правила
1. **Один блок — один CSS-файл** (`css/<block>.css`) и, если нужен скрипт, один JS-файл (`js/<block>.js`).
2. Классы по БЭМ: `.block`, `.block__element`, `.block--modifier`. Стили блока не трогают чужие блоки.
3. Цвета, шрифты, отступы — только через переменные из `:root` в `main.css`. Новые значения добавляем туда.
4. Адаптив (`@media`) пишем внутри файла самого блока, в конце.
5. Новый блок: создать `css/<block>.css` → подключить `<link>` в `index.html` после `main.css`.
6. JS без модулей и сборщика: каждый файл — IIFE, подключается через `<script defer>`.

## Фон hero
Фон — `img/herogz.webp`, путь задан в `css/hero.css` (`--hero-bg-image`).
Чтобы заменить, положите новый файл в `img/` и поменяйте путь. Класс `hero--has-image` у секции отключает заглушку-сетку.

## Добавление фото в «Произведённые работы»
1. Подготовьте фото в формате 3:2 (например, 1200×800), WebP или JPEG до 100–150 КБ, положите в `img/works/`.
2. В `index.html` скопируйте `<article class="projects__card">` в конец `<div class="projects__list">`.
3. Поменяйте `src` и `alt`. Город в подписи сейчас везде «Краснодар».

## Добавление документа в «Документацию»
1. Положите файл в `docs/`.
2. В `index.html` скопируйте `<article class="docs__card">` в конец `<div class="docs__list">`.
3. Поменяйте заголовок и `href="docs/…"`. Кнопка «Показать больше» работает так же, как в проектах.

## Новая секция с кнопкой «Показать больше»
Добавьте секции атрибуты `data-show-more data-initial="3" data-step="3"`, списку — `data-show-more-list`,
а блок с кнопкой оформите как `<div class="show-more" data-show-more-footer hidden><button class="show-more__btn" data-show-more-btn>…`.
Писать новый JS не нужно.

## Порядок меню и секций
Пункты меню в `header` идут в том же порядке, что секции на странице:
Услуги (`#services`) → Документы (`#docs`) → О компании (`#about`) → Контакты (`#contacts`).
Добавляя секцию, добавьте пункт меню в то же место списка.

## Подвал
Телефон, почта и адрес офиса в подвале и телефон в шапке — реальные. Режим работы в подвале пока заглушка, замените на реальный в `index.html`.
Подвал имеет `id="contacts"`, поэтому пункт меню «Контакты» прокручивает страницу вниз к нему.
Цвет фона подвала — токен `--color-footer-bg` в `main.css`.

## Учебные материалы в Hero
В первых двух карточках Hero открываются списки PDF-документов. Списки и поведение карточек находятся в `index.html` и `js/hero-materials.js`, оформление — в `css/hero.css`.

Как устроена карточка: `<article class="hero__card hero__card--interactive">` с заголовком `<h2>`, текстом и кнопкой `.hero__card-action` (растянута на всю карточку, поэтому нажимается любое место). Кнопка связана с панелью через `aria-controls` и `data-hero-toggle="<имя>"`; панель — `<section data-hero-panel="<имя>" hidden aria-labelledby="…">`.

Поведение (`js/hero-materials.js`): пока панель открыта, карточки под ней `inert`; фокус уходит на заголовок панели, а при закрытии («Назад к разделам» или Esc) возвращается на карточку. Высота блока растёт под содержимое (`min-height` у `.hero__stage`), текст в карточках не обрезается.
- Памятки по узлам: `docs/training-nodes/` (10 PDF).
- Инструкции по материалам: `docs/training-materials/` (7 PDF).
Чтобы добавить файл, положите PDF в соответствующую папку и добавьте ссылку в нужный список `[data-hero-panel]` в `index.html`.
